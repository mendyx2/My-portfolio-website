HOW TO ADD YOUR PHOTOS
=======================

This folder is where all the site's real photos live. Nothing needs to be
touched in script.js except the file paths that are already set up for you.

1) images/profile.jpg
   Your hero/profile photo.

2) images/about/
   - workspace.jpg
   - design.jpg
   - code.jpg
   (the "behind the scenes" photo strip in the About section)

3) images/projects/
   Web & AI projects (ONE cover photo each):
   - orbital-dash.jpg
   - northwind-admin.jpg
   - nacham-tech.jpg
   - ecom-voice-agent.jpg
   - seo-analyzer.jpg

   Mobile projects (a few screenshots each, shown as a carousel):
   - lumen-budget-1.jpg / lumen-budget-2.jpg / lumen-budget-3.jpg
   - flavor-journal-1.jpg / flavor-journal-2.jpg / flavor-journal-3.jpg

Just drop a file in with the exact name above and refresh the page — no
code changes needed. If a file isn't there yet, the site shows a nice
gradient placeholder that tells you exactly which filename it's waiting for.

Want to add a NEW project or change a filename? Open script.js, find the
PROJECTS list near the top, and edit the "image" or "images" field for
that project to match whatever path/filename you want to use.
